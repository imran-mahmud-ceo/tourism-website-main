# Bangladesh Tourism Management & Booking Platform

This is a comprehensive tourism website built with Django, designed to manage and facilitate travel bookings in Bangladesh. The platform features hotel bookings, tour packages, destination discovery, and travel blogs.

## Features

- Hotel bookings
- Tour packages
- Destination discovery
- Travel blogs
- User accounts and authentication
- Booking management
- Contact forms

## Technologies Used

- Django
- Python
- HTML/CSS/JavaScript
- Bootstrap
- SQLite (for development)

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/imran-mahmud-ceo/tourism-website-main.git
   ```

2. Navigate to the project directory:
   ```
   cd tourism-website-main
   ```

3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

4. Run migrations:
   ```
   python manage.py migrate
   ```

5. Create a superuser:
   ```
   python manage.py createsuperuser
   ```

6. Run the server:
   ```
   python manage.py runserver
   ```

## Usage

- Access the website at `http://localhost:8000`
- Admin panel at `http://localhost:8000/admin`
